## Install on macOS

Paste into Terminal. This selects Apple Silicon or Intel automatically and installs to your account:

```sh
(
  set -eu
  target=x86_64-apple-darwin
  if [ "$(sysctl -n hw.optional.arm64 2>/dev/null || true)" = 1 ]; then
    target=aarch64-apple-darwin
  fi
  asset="downloader-cli-0.1.24-$target.tar.gz"
  base=https://github.com/ArionStudio/local-downloader/releases/download/app-v0.1.24
  temporary="$(mktemp -d)"
  cd "$temporary"
  curl -fL --retry 3 -o "$asset" "$base/$asset"
  curl -fL --retry 3 -o "$asset.sha256" "$base/$asset.sha256"
  shasum -a 256 -c "$asset.sha256"
  tar -xzf "$asset"
  mkdir -p "$HOME/.local/bin"
  install -m 755 downloader-cli "$HOME/.local/bin/downloader-cli"
  echo "Guide and adapter: $temporary"
)
export PATH="$HOME/.local/bin:$PATH"
downloader-cli --version
downloader-cli tools install all
```

Keep the PATH line in `~/.zshrc`, or configure your agent to use `$HOME/.local/bin/downloader-cli`. Linux and Windows installation commands are in the [integration guide](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.24/docs/cli.md#download-and-install).

After installing:

```sh
downloader-cli --version
downloader-cli tools install all
downloader-cli download 'VIDEO_URL' --browser firefox --profile xrbazaar --events
```

The CLI installs native yt-dlp, FFmpeg, and ffprobe for the current system. You can also use existing copies on PATH. Browser-cookie access uses the logged-in OS account; macOS may ask to unlock or allow access to Keychain.

Mac CLI binaries and desktop apps are ad-hoc signed, not Apple notarized. If Gatekeeper blocks a downloaded executable, allow that specific file in **System Settings → Privacy & Security → Open Anyway** after trying to run it. Do not disable Gatekeeper globally.

## Fixes in this release

- Encrypted Squarespace videos download again when yt-dlp hands them to FFmpeg. This happens with a system or pip yt-dlp, which lacks pycryptodomex. FFmpeg 7.1 and newer rejected their segment links because they have no file extension, and the job stopped with "ffmpeg exited with code 183". The download now retries once with that check off. If the retry also fails, the error points to the app-managed yt-dlp in Settings > Tools.
- On Linux, a copy installed by a system package, for example unpacked into /opt, no longer fails in-app updates with "Permission denied". The update panel explains how to update it and disables the install button. The same applies to an AppImage stored in a folder the user cannot write to.
- All 0.1.23 fixes remain included, including Instagram extraction and separate source and browser-cookie errors.

XRBAZAAR downloads preserve originals and create verified MP4 copies using H.264, yuv420p, at most 1280 pixels on the longest edge and 30 fps, AAC audio at 48 kHz where present, faststart, and a 100 MiB size limit. The CLI supports the same preparation through `--profile xrbazaar` and `prepare`.

Desktop installers remain separate assets; `latest.json` serves the desktop updater. CLI archives include the integration guide and Node adapter. The [0.1.22 Mac verification record](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.22/docs/verification/macos-0.1.22.md) documents that release's runtime checks and external-site limitations. Native 0.1.24 release checks run separately in the release workflow.
