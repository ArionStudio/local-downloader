# Downloader 0.1.19

Standalone CLI binaries are included in this release. Download and extract the archive for your machine. No Rust, Node, desktop app, or source checkout is required to run the CLI.

**[Installation and agent integration instructions](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.19/docs/cli.md#download-and-install)** include macOS/Linux commands that detect your CPU, Windows PowerShell instructions, browser cookies and profiles, JSON requests, progress events, cancellation, and XRBAZAAR preparation. Each archive includes this guide and the Node adapter. They are also separate release assets, `cli.md` and `adminhub-downloader.mjs`.

Verify your download with [SHA256SUMS](https://github.com/ArionStudio/local-downloader/releases/download/app-v0.1.19/SHA256SUMS), or the archive's matching `.sha256` file.

## Install on macOS

Paste into Terminal. This selects Apple Silicon or Intel automatically and installs to your account:

```sh
(
  set -eu
  target=x86_64-apple-darwin
  if [ "$(sysctl -n hw.optional.arm64 2>/dev/null || true)" = 1 ]; then
    target=aarch64-apple-darwin
  fi
  asset="downloader-cli-0.1.19-$target.tar.gz"
  base=https://github.com/ArionStudio/local-downloader/releases/download/app-v0.1.19
  temporary="$(mktemp -d)"
  cd "$temporary"
  curl -fL --retry 3 -o "$asset" "$base/$asset"
  curl -fL --retry 3 -o "$asset.sha256" "$base/$asset.sha256"
  shasum -a 256 -c "$asset.sha256"
  tar -xzf "$asset"
  mkdir -p "$HOME/.local/bin"
  install -m 755 downloader-cli "$HOME/.local/bin/downloader-cli"
  echo "Guide and adapter: $temporary"
)
export PATH="$HOME/.local/bin:$PATH"
downloader-cli --version
downloader-cli tools install all
```

Keep the PATH line in `~/.zshrc`, or configure your agent to use `$HOME/.local/bin/downloader-cli`. Linux and Windows installation commands are in the [integration guide](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.19/docs/cli.md#download-and-install).

After installing:

```sh
downloader-cli --version
downloader-cli tools install all
downloader-cli download 'VIDEO_URL' --browser firefox --profile xrbazaar --events
```

The CLI installs native yt-dlp, FFmpeg, and ffprobe for the current system. You can also use existing copies on PATH. Browser-cookie access uses the logged-in OS account; macOS may ask to unlock or allow access to Keychain.

Mac CLI binaries and desktop apps are ad-hoc signed, not Apple notarized. If Gatekeeper blocks a downloaded executable, allow that specific file in **System Settings → Privacy & Security → Open Anyway** after trying to run it. Do not disable Gatekeeper globally.

This release also fixes native tool selection and desktop video previews, shows completed files while batches are still running, retains files after cancellation, and adds XRBAZAAR preparation and clearer download/file layouts. Desktop installers remain separate assets; `latest.json` serves the desktop updater.
