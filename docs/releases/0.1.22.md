## Install on macOS

Paste into Terminal. This selects Apple Silicon or Intel automatically and installs to your account:

```sh
(
  set -eu
  target=x86_64-apple-darwin
  if [ "$(sysctl -n hw.optional.arm64 2>/dev/null || true)" = 1 ]; then
    target=aarch64-apple-darwin
  fi
  asset="downloader-cli-0.1.22-$target.tar.gz"
  base=https://github.com/ArionStudio/local-downloader/releases/download/app-v0.1.22
  temporary="$(mktemp -d)"
  cd "$temporary"
  curl -fL --retry 3 -o "$asset" "$base/$asset"
  curl -fL --retry 3 -o "$asset.sha256" "$base/$asset.sha256"
  shasum -a 256 -c "$asset.sha256"
  tar -xzf "$asset"
  mkdir -p "$HOME/.local/bin"
  install -m 755 downloader-cli "$HOME/.local/bin/downloader-cli"
  echo "Guide and adapter: $temporary"
)
export PATH="$HOME/.local/bin:$PATH"
downloader-cli --version
downloader-cli tools install all
```

Keep the PATH line in `~/.zshrc`, or configure your agent to use `$HOME/.local/bin/downloader-cli`. Linux and Windows installation commands are in the [integration guide](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.22/docs/cli.md#download-and-install).

After installing:

```sh
downloader-cli --version
downloader-cli tools install all
downloader-cli download 'VIDEO_URL' --browser firefox --profile xrbazaar --events
```

The CLI installs native yt-dlp, FFmpeg, and ffprobe for the current system. You can also use existing copies on PATH. Browser-cookie access uses the logged-in OS account; macOS may ask to unlock or allow access to Keychain.

Mac CLI binaries and desktop apps are ad-hoc signed, not Apple notarized. If Gatekeeper blocks a downloaded executable, allow that specific file in **System Settings → Privacy & Security → Open Anyway** after trying to run it. Do not disable Gatekeeper globally.

## Fixes in this release

- Fix HTTPS video trimming with standalone macOS FFmpeg by using the system certificate bundle. Explicit `SSL_CERT_FILE` settings remain respected; TLS verification stays enabled.

- Video previews now show cached thumbnail posters before playback, including clips shorter than a second. Offscreen previews load as you scroll.
- Preview volume starts at 10% and is shared across all videos. Volume and mute are remembered after restart. Adjust them in a player or under Settings → Preview audio.
- Video-only downloads remove audio even when the source offers only a combined video/audio file. A file becomes ready after that step finishes.
- Download failures retain the source's error message, such as a login requirement, instead of showing only an exit code.
- Completed files remain available during a batch and after cancellation. Open video, Show in folder, Copy path, and inline previews are available from Files and Activity.

XRBAZAAR downloads preserve originals and create verified MP4 copies using H.264, yuv420p, at most 1280 pixels on the longest edge and 30 fps, AAC audio at 48 kHz where present, faststart, and a 100 MiB size limit. The CLI supports the same preparation through `--profile xrbazaar` and `prepare`.

Desktop installers remain separate assets; `latest.json` serves the desktop updater. CLI archives include the integration guide and Node adapter. See the [Mac verification record](https://github.com/ArionStudio/local-downloader/blob/app-v0.1.22/docs/verification/macos-0.1.22.md) for tested behavior and external-site limitations.
